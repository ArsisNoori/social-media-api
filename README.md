# Social Media API

A RESTful API for a simple social media platform built with Django REST Framework.

This project is being developed as a learning project while following professional backend development practices.

## Features

- Custom User Model
- User Profiles
- Authentication
- Authorization & Permissions
- CRUD for Posts
- Like & Unlike Posts
- Follow & Unfollow Users
- Comments
- Pagination
- Filtering & Search
- PostgreSQL Database
- Docker (Coming Soon)

---

## Tech Stack

- Python
- Django
- Django REST Framework
- PostgreSQL
- Git & GitHub
- Docker (Planned)

## Getting Started

### Clone the project

```bash
git clone git@github.com:ArsisNoori/social-media-api.git
```

### Create virtual environment

```bash
python -m venv venv
```

### Activate

Linux/macOS

```bash
source venv/bin/activate
```

Windows

```bash
venv\Scripts\activate
```

### Install requirements

```bash
pip install -r requirements.txt
```
